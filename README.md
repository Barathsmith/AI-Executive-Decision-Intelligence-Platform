
# AI Business Strategy & Executive Decision Intelligence Platform

## Business Requirement
Leaders need to analyze sales, customer feedback, financial, operational metrics manually - time consuming.

## Our Solution
AI-powered platform that analyzes business info, identifies changes, explains performance, provides actionable recommendations.

## Features (As per Question)
- Process structured & unstructured data
- Analyze sales & business performance
- Extract KPIs
- Identify trends & anomalies (IQR)
- Analyze customer feedback (Sentiment)
- Compare performance across periods
- Identify significant changes
- Explain possible reasons
- Identify risks & opportunities
- Generate executive summaries
- Provide AI recommendations
- Scenario-based analysis (sliders)
- Interactive executive dashboard + AI assistant

## Tech & Why
- Streamlit: Executive Dashboard - No HTML needed
- Pandas/Numpy: KPI, Trend, Period comparison
- IQR: Robust anomaly detection
- Rule-based Sentiment: Fast, no API cost

## How to Run
pip install streamlit pandas numpy
streamlit run app.py
